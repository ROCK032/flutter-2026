# Уровень 3

Громкая ошибка:
Tried to listen to a value exposed with provider, from outside of the widget tree.

Причина: watch<Cart>() вызван внутри onPressed.
Исправление: использовать read<Cart>() в обработчике нажатия.

Тихая ошибка:
С read<Cart>() в CartBadge.build исключений не возникло.
Значок показывал 0 и 0 ₸, хотя экран корзины показывал
две книги и 7300 ₸.

Причина: CartBadge не подписался на изменения модели.
Исправление: вернуть watch<Cart>() в build.

# Уровень 5

## Where does it live?

- Корзина — provided: общий Cart находится в ChangeNotifierProvider над MaterialApp и доступен обоим экранам.
- Текст поиска — ephemeral: _query хранится в State экрана BooksScreen и нужен только каталогу.
- Признак сворачивания итога, если добавить такой переключатель, — ephemeral: его следует хранить локально на CartScreen, потому что он меняет только отображение этого экрана.
- Режим темы при наличии переключателя — lifted: состояние корневого виджета над MaterialApp, потому что оно задаёт themeMode всего приложения.

SnackBar показывается в виджете только при true из Cart.add.
Диалог очистки возвращает bool; после await проверяется context.mounted.
Модель Cart хранит данные и правила, интерфейс принимает решения о сообщениях и диалогах.
