# Практика 2 — каталог библиотеки на Dart

Запускай команды из папки `practice_2`:

```powershell
dart run lib/week02/main.dart
dart analyze
dart test
```

В работе используется чистый Dart. Интерфейса Flutter и виджетов здесь нет.

## Что находится в файлах

| Файл | Назначение |
| --- | --- |
| `lib/week02/data.dart` | Шесть исходных записей о книгах |
| `lib/week02/models.dart` | Author, Genre, LibraryItem, Book, Magazine, Borrowable и Ghost |
| `lib/week02/catalogue.dart` | Library: поиск, запросы к коллекциям, отчёт |
| `lib/week02/shelf_state.dart` | Три состояния полки и статистика в record |
| `lib/week02/main.dart` | Сборка каталога и демонстрация всех уровней |
| `test/week02_test.dart` | Проверки неполных данных, поиска, коллекций и состояний |

## Как объяснить программу за минуту

«Я моделирую каталог библиотеки. Исходные записи хранятся в списке Map.
Конструктор Book.fromJson превращает каждую запись в типизированную книгу
и задаёт значения по умолчанию для отсутствующих данных.
Book и Magazine наследуют LibraryItem. Миксин Borrowable добавляет книгам
метод borrowLabel. Ghost реализует интерфейс LibraryItem самостоятельно.
Library хранит элементы, ищет книги и выполняет запросы к коллекциям.
Состояние полки задаётся одним из трёх подтипов ShelfState,
а statsOf возвращает количество книг и среднее число страниц в record».

Это ориентир для собственного объяснения: разберись в примерах ниже,
чтобы суметь ответить на уточняющие вопросы.

## Уровень 1 — классы

- `final` запрещает повторное присваивание полю. Содержимое final-списка при этом может меняться.
- `const` позволяет создавать константные объекты с известными заранее значениями.
- `required` требует передать именованный параметр. Пустую строку он не запрещает.
- `String?` допускает строку или `null`.
- `factory Book.fromJson` получает Map, подготавливает данные и возвращает Book.
- `as int?` проверяет тип значения. Он не преобразует строку `'464'` в число.
- `isLong` — геттер: вычисляет `pages > 400`. Вызывается без круглых скобок.
- `copyWith` создаёт новый объект, сохраняя значения, для которых не передали замену.
- `toString` определяет текстовое представление объекта для print.

Пример: `book.copyWith(pages: 120)` возвращает новую книгу. Исходная книга
сохраняет 464 страницы. При 400 страницах isLong равен false, при 401 — true.

## Уровень 2 — три разных механизма

| Запись | Что происходит |
| --- | --- |
| `Book extends LibraryItem` | Наследует поля и реализацию isOld; реализует describe |
| `Ghost implements LibraryItem` | Обязан сам объявить title, year, isOld и describe; код LibraryItem не наследует |
| `Book ... with Borrowable` | Получает готовый метод borrowLabel из миксина |

`abstract` запрещает создавать LibraryItem напрямую.
`String describe();` задаёт метод без реализации.
`super.title` передаёт параметр конструктору родителя.
`on LibraryItem` ограничивает применение миксина и позволяет ему обращаться к title.

В `List<LibraryItem>` можно хранить Book, Magazine и Ghost. Один вызов
`item.describe()` вызывает реализацию конкретного объекта — это полиморфизм.

## Уровень 3 — null safety

Разбери выражение:

```dart
findByTitle(title)?.author.country ?? 'unknown'
```

Если книга не найдена, `?.` прекращает дальнейшее обращение по этой цепочке
и результат получается null. Если книга найдена, получаем страну её автора.
`??` подставляет `'unknown'`, когда результат null, включая неизвестную страну.

- `??=` присваивает значение только тогда, когда слева null. Так кешируется отчёт.
- После `add` кеш сбрасывается, чтобы новый отчёт содержал добавленный элемент.
- Добавляй элементы через `add`, а не напрямую через `items.add`: иначе кеш не сбросится.
- `late final openedAt` присваивается при `open()`. Читать его до `open()` нельзя.
- Повторный `open()` сохраняет первое время открытия.
- В main поле description копируется в локальную переменную. После проверки на null можно безопасно обращаться к length.

## Уровень 4 — коллекции

- `whereType<Book>()` выбирает книги из общего списка элементов.
- `map` преобразует каждый элемент: например, книгу в название.
- `where` оставляет элементы, подходящие под условие.
- `fold` накапливает результат с начального значения, например сумму страниц с нуля.
- `reduce` требует хотя бы один элемент; поэтому для потенциально пустой коллекции удобнее fold.
- `toSet()` оставляет уникальные значения.
- `...authorNames` вставляет элементы набора в список.
- `for` внутри литерала списка создаёт строки для книг.
- `if` внутри литерала добавляет предупреждение только при неполных данных.

Все шесть запросов в Library записаны одним выражением. Обычные циклы
в main и findByTitle не относятся к этим запросам.

В booksByAuthor fold начинает с пустой Map. Для каждой книги он переносит
накопленные пары через spread и увеличивает счётчик её автора на один.

## Уровень 5 — sealed, patterns и records

`sealed class ShelfState` задаёт закрытую иерархию. Прямые подтипы объявлены
в той же библиотеке Dart: Empty, Ready и Broken.

`switch` — выражение, которое возвращает описание. Ветка
`Ready(books: final books)` одновременно распознаёт состояние Ready
и извлекает его поле books в локальную переменную.

В switch нет default: если добавить четвёртый прямой подтип, анализатор
потребует обработать его. Именно поэтому перечисляются все три случая.

`statsOf` возвращает record с именованными полями:

```dart
(count: 6, avgPages: 369.8333333333333)
```

Доступ: `stats.count` и `stats.avgPages`. Это не List и не отдельный класс.
Порядок отображения именованных полей при print может отличаться от записи в коде.

## Ожидаемые результаты

- 6 книг, плюс журнал и Ghost в общем каталоге: всего 8 элементов.
- После 2010 года: The Pragmatic Programmer, Refactoring, Broken Record.
- Всего страниц: 2219. Среднее по шести книгам: 369.83.
- Broken Record получает pages = 0, genre = unknown, country = null, description = null.
- Design Patterns сохраняет 395 страниц и жанр theory, но страна неизвестна.
- countryOf для неизвестной книги или неизвестной страны возвращает unknown.
- Среднее для пустой библиотеки равно 0.0.

## Принятые решения и неточность задания

1. В задании не указан порог isOld. Здесь это год строго меньше 2000.
2. Неизвестные страницы представлены нулём и входят в среднее. Журналы и Ghost в среднее не входят.
3. В текущем copyWith null означает «сохранить прежнее значение», поэтому description через null не очищается.
4. fromJson обрабатывает отсутствующие поля, но не исправляет произвольные неверные типы входных данных.
5. В задании противоречие: образец data.dart содержит dynamic, но жёсткое правило запрещает dynamic вне параметра fromJson. Выбран строгий запрет: в data.dart заменена только аннотация типа на Object?. Все шесть записей, ключи и значения сохранены. Единственный dynamic остался в параметре Book.fromJson.
