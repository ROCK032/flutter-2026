# Коротко о коде перед защитой

## Порядок чтения файлов

1. `lib/models/event.dart` — какие данные есть у события и как работает `copyWith`.
2. `lib/screens/shell_screen.dart` — где хранятся события и профиль, сортировка и навигация.
3. `lib/screens/events_tab.dart` — поиск и фильтры через `where`.
4. `lib/widget/event_list.dart` — выбор списка или сетки через `LayoutBuilder`.
5. `lib/screens/detail_screen.dart` — запись, отмена записи, таймер, редактирование и удаление.
6. `lib/screens/event_form_screen.dart` — проверка полей, сохранение и `PopScope`.

## Как проходят данные

`ShellScreen` хранит общий список `_events` и `_profile`.
Вкладки получают данные через конструктор, а изменения отправляют обратно через функции — callbacks.
Нажатие карточки вызывает `_openEvent(event)` в Shell.
Подробности получают `DetailArguments`: событие, профиль и callbacks.
При регистрации `copyWith` создаёт новый Event, `setState` обновляет подробности, `onChanged` заменяет событие в Shell.
Форма получает Event для редактирования либо null для создания.
`Navigator.pop(context, result)` возвращает новый Event; вызывающий экран ждёт его через `await Navigator.pushNamed<Event>`.
Обычный выход возвращает null: исходные данные не меняются.

## Что означают основные конструкции

| Конструкция | Что сказать своими словами |
| --- | --- |
| `final` | Полю нельзя присвоить другое значение после инициализации. |
| `factory Event` | Создаёт Event и защищает список участников через `List.unmodifiable`. |
| `Event._` | Приватный именованный конструктор; доступен внутри файла модели. |
| `copyWith` | Возвращает новую модель с заменой указанных полей. |
| `get count` | Вычисляет число участников из списка, отдельно число не хранится. |
| `places` | Record с двумя именованными значениями: taken и free. |
| `sealed Countdown` | Ограниченный набор вариантов, все они перечислены в switch. |
| `where` | Оставляет элементы, прошедшие условие поиска/фильтра. |
| `map` | Превращает категории enum в пункты выпадающего списка. |
| `fold` | Накапливает число мероприятий с участием пользователя. |
| `any` | Проверяет, есть ли хотя бы один подходящий участник. |
| `Expanded` | Даёт виджету оставшееся место внутри Row или Column. |
| `mounted` | Проверяет, что экран ещё существует после await. |
| `dispose` | Освобождает контроллеры, фокус и таймер. |

## Важные места

- **Сортировка:** в Shell сначала создаётся копия списка. Будущие события идут первыми, затем сравниваются даты. Исходный `_events` не сортируется.
- **Поиск:** сравниваются названия без учёта регистра; категория и показ прошлого проверяются отдельно.
- **Сетка:** ширина от 600 px, число колонок — `ceil(width / 360)`. Доступную ширину даёт `LayoutBuilder`.
- **Избранное:** меняется `isFavourite` у копии Event, вкладка избранного использует `where`.
- **Профиль:** имя и группа сохраняются по Enter/Done, группа проверяется RegExp.
- **Тема:** ThemeMode хранится в MyApp, выше MaterialApp. Профиль передаёт новое значение через callback.
- **Онлайн:** меняются подпись и клавиатура поля места; ссылка должна содержать `://`.
- **Дата и время:** выбираются отдельно, при сохранении собираются в один DateTime. Для нового события он должен быть в будущем.
- **Сохранение:** один `validate()`, затем секундная задержка, прогресс и заблокированная кнопка. После await проверяется mounted.
- **PopScope:** `_hasChanges` сравнивает значения с исходными. `_dirty` блокирует возврат, диалог позволяет продолжить или выйти. При сохранении разрешаем выход и возвращаем результат.
- **Таймер:** запускается раз в минуту в initState, отменяется в dispose. После редактирования времени отсчёт пересчитывается.
- **Длительность:** в этой реализации событие длится один час, потому что отдельного времени окончания в модели нет.
- **Сброс:** возвращает seed и пустой профиль; новые ключи вкладок очищают черновики и фильтры.

## Быстрая ручная проверка

1. Создай событие через «+», затем отредактируй через меню «⋮».
2. Измени поле формы, нажми «Назад»: проверь «Продолжить» и «Выйти».
3. Укажи имя в профиле и нажми Enter. Запишись, проверь «Вы» и число участников, отмени запись.
4. Открой полное событие: без записи кнопка отключена; участник может отменить свою запись.
5. Проверь светлую/тёмную темы, поиск, фильтры, избранное и удаление.

На защите нужно объяснять и менять код самостоятельно. Комментарии — подсказки для чтения, а не замена пониманию.
